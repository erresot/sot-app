SOT · Visita + Evolução — instalação

Feito uma vez, por alguém logado na conta equipersot@gmail.com. Tempo: ~25 minutos. Custo: zero.

Antes de começar: a conta equipersot precisa ter acesso de leitor ao Google Doc “Internograma HCI” (peça ao dono do documento para compartilhar). E troque a senha da conta, já que ela foi escrita numa conversa.

Parte 1 — Google Cloud (libera o login com Google)

  1. Entre em console.cloud.google.com logado no equipersot. Aceite os termos.
  2. No topo, Selecionar projeto → Novo projeto. Nome: SOT App → Criar. Confirme que ele está selecionado.
  3. Menu ☰ → APIs e serviços → Biblioteca → procure Google Drive API → Ativar.
  4. Menu ☰ → APIs e serviços → Tela de consentimento OAuth (pode aparecer como “Google Auth Platform”) → Começar:
    • Nome do app: SOT App · E-mail de suporte: equipersot@gmail.com
    • Público: Externo
    • Dados de contato: equipersot@gmail.com → Criar
  5. Em Público (Audience) → Usuários de teste → Adicionar usuários → equipersot@gmail.com → Salvar. (Deixe o app em “Teste”; não precisa publicar.)
  6. Em Acesso a dados (Data access) → Adicionar ou remover escopos → marque:
    • .../auth/drive.file (criar e editar os arquivos do app)
    • .../auth/drive.readonly (ler o internograma)
    → Atualizar → Salvar.
  7. Em Clientes (ou Credenciais) → Criar cliente → Tipo: Aplicativo da Web → Nome: SOT App web.
    Em Origens JavaScript autorizadas adicione o endereço da Parte 2, só o domínio, ex.: https://equipersot.github.io → Criar.
  8. Copie o ID do cliente (termina em .apps.googleusercontent.com). Você vai colar no config.js.

Parte 2 — Publicar o app (GitHub Pages)

  1. Crie uma conta em github.com com o e-mail equipersot (o nome de usuário vira o endereço; ex.: equipersot).
  2. New repository → nome sot-app → Public → Create. (O código fica visível, mas não tem nenhum dado de paciente. Os dados ficam só no Drive e nos aparelhos.)
  3. Add file → Upload files → arraste todos os arquivos desta pasta (index.html, evo.html, sync.js, config.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png) → Commit.
  4. Abra config.js no GitHub → ✏️ editar → cole o ID do cliente em CLIENT_ID: '...' → Commit.
  5. Settings → Pages → Source: Deploy from a branch → Branch main / (root) → Save. Em 1–2 min aparece o endereço: https://equipersot.github.io/sot-app/
  6. Se o nome de usuário do GitHub for outro, volte à Parte 1, passo 7, e ajuste a origem autorizada.

Parte 3 — Usar no celular e no PC

  1. Abra o endereço no Chrome (Android) ou Safari (iPhone) → menu → Adicionar à tela inicial. No PC, abra no Chrome e salve nos favoritos ou instale (ícone ⊕ na barra).
  2. Aba ⚙ Internograma → Conectar ao Google → escolha equipersot@gmail.com.
  3. Vai aparecer “O Google não verificou este app”. É esperado num app interno em teste: Avançado → Acessar SOT App → permita o acesso ao Drive.
  4. Escreva seu nome no campo da mesma tela (fica registrado em cada alteração e foto).
  5. Atualizar do Google Doc → a lista de pacientes aparece. Pronto.
Como funciona no dia a dia
  • Tudo é salvo no aparelho a cada toque. Sem internet, o app continua funcionando e mostra “📴 … aguardando envio”; quando a rede volta, ele envia sozinho.
  • O app abre mesmo sem internet (depois de aberto uma vez com rede).
  • O login com Google dura cerca de 1 hora. Quando expirar, a barra fica “🔑 toque para reconectar”. Nada se perde enquanto isso.
  • No Drive do equipersot é criada a pasta SOT App - Visitas: pacientes/ (um arquivo por paciente), fotos/ (por paciente) e backups/ (uma cópia completa por dia, por aparelho).
  • Dois residentes no mesmo paciente: em cada item vale a alteração mais recente, e as pendências se somam.
  • Backup manual: ⚙ → Baixar backup. Para restaurar: ⚙ → Restaurar backup (mescla, não apaga).

Segurança

  • O link sozinho não mostra nenhum dado: é preciso fazer login com a conta da equipe.
  • Os dados ficam guardados no navegador do aparelho. Use bloqueio de tela no celular. Ao trocar de aparelho ou emprestar o PC: ⚙ → Apagar tudo deste aparelho (a cópia no Drive continua).
  • As fotos não vão para a galeria do celular quando tiradas pelo botão 📸 do app.

Atualizar o app no futuro

  1. Substitua os arquivos no GitHub (Upload files).
  2. Em sw.js, troque var V = 'sot-v1' por 'sot-v2' (e assim por diante). Isso força os celulares a baixarem a versão nova.
  3. Não sobrescreva o config.js (ele tem o seu ID do cliente).
